# Исходное задание — Assignment 5: Calculator with pages

## Статус

Assignment 5. На странице задания указано, что работу требуется отправить; деление на обязательную и Bonus/Optional-части отсутствует.

## Что требуется

- Разделить приложение-калькулятор на две страницы: `Calculator` и `History`.
- Использовать стековую навигацию React Navigation для переходов между страницами.
- На странице `Calculator` разместить калькулятор и кнопку перехода на страницу `History`.
- На странице `History` показывать историю вычислений с помощью компонента `FlatList`.
- Страницы `Calculator` и `History` должны быть реализованы как отдельные компоненты.

## Ожидаемый результат

Приложение открывает страницу калькулятора, позволяет перейти с неё на отдельную страницу истории и выводит выполненные вычисления списком `FlatList`. Переходы между двумя страницами выполняются средствами React Navigation Stack.

## Что сдавать

В источнике указано только требование отправить работу (`Make a submission`). Формат файлов, способ упаковки и ссылка на репозиторий для этого задания отдельно не указаны.

## Примечания к трактовке

- На иллюстрации показан калькулятор с операциями сложения и вычитания, однако текст задания называет его просто калькулятором и не перечисляет полный набор арифметических операций.
- Изображения экранов являются примером результата; требование точно воспроизвести их оформление в тексте отсутствует.
- Источник не требует постоянного хранения истории после закрытия приложения и не задаёт способ хранения данных.
- Требования к тестам, обработке ошибочного ввода и конкретной версии React Native или Expo в источнике не указаны.
